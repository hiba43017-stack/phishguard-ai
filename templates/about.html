PhishGuard AI

An AI-powered phishing email detection system combining rule-based heuristics with local Large Language Models via Ollama. Built as a BCA final year project demonstrating real-world cybersecurity concepts.

Python 3.11+ Flask Ollama + Llama 3.2 SQLite Pytest

📊 Risk Score System
Score Range Level Verdict Recommended Action
0 – 24 LOW Safe No action needed. Remain cautious.
25 – 49 MEDIUM Suspicious Verify sender independently before responding.
50 – 74 HIGH Suspicious Do not click links. Report to IT.
75 – 100 CRITICAL Malicious Delete immediately. Report as phishing. Change passwords if interacted.

⚠️ Project Limitations
⚠️
  • This system is for educational purposes only.
  • AI analysis requires Ollama and llama3.2:3b to be installed locally.
  • The rule engine uses pattern matching — sophisticated attacks may evade detection.
  • False positives (legitimate emails flagged) and false negatives (phishing missed) are possible.
  • Results should always be verified by a human security professional for critical decisions.
  • Only plain-text and simple HTML email bodies are supported (no attachment scanning).
